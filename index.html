How I build systems

Three constraints that shape every architectural decision, from schema design to deployment strategy.

resilience.go
Resilience by design
webhook retries without dedup no per-device auth boundary dedup + cell filters + RBAC per-device PIN + auto lockout // distributed rate-limiting

Systems that fail gracefully under load. Webhook deduplication and dynamic RBAC at IPCOM; per-device zero-trust auth at BYONDIT — same instinct, different domain.

bridge.go
Incremental modernization
SOAP/Mule ESB core JSON Schema Draft-7 rigidity Go REST adapter (KrakenD) Draft-2020 dynamic workflows // no big bang rewrites

Legacy systems aren't replaced in one sprint. I build adapter bridges that let old and new run in parallel until the risk window closes — from banking cores to voice-flow schemas.

pipeline.yml
Pipeline efficiency
6-hour sequential CI runs no dependency graph affected-only builds remote artifact caching // 1→20+ builds/day, same quota

CI/CD bottlenecks compound across every engineer on the team. Dependency-graph analysis finds the real blocking jobs, not the obvious ones — and Terraform audits right-size the infra underneath.

Shipped systems, measured outcomes

Three engagements across CPaaS, fintech, and independent consulting — each with a friction, a decision, and a number.

High Concurrency
IPCOM
Backend Engineer · Nov 2024 – May 2025
Friction
A CPaaS platform needed to sustain 1M+ real-time messages daily across Web Chat, WhatsApp and RCS, with legacy SIP components limiting the voice layer.
Engineering applied
Built the multi-channel messaging core in Go + Redis + NATS with webhook dedup and RBAC via a custom OPA policy engine. Migrated SIP to PJSIP with distributed rate-limiting (Gubernator) and a full OpenTelemetry/Grafana observability layer.
Output
1M+ msgs/day -35% MTTR -40% DB load
Zero Downtime
BYONDIT
Backend Engineer · Nov 2022 – Jul 2023
Friction
Tigo Money's banking core exposed only SOAP over Mule ESB. Three LATAM markets needed mobile P2P transfers and bill pay with zero tolerance for transaction errors.
Engineering applied
Go REST layer bridging SOAP to mobile channels via KrakenD, with idempotency tokens per transaction, OAuth2/OIDC federation on AWS Cognito, and per-device zero-trust auth to cut fraud.
Output
3 markets 0 downtime -30% integration time
Dev Velocity
Upwork
Independent Consulting · May 2021 – Jun 2026
Friction
Distributed Go backends running 6-hour sequential CI pipelines. GitHub Actions quota allowed roughly one full build per day, blocking every PR merge across the team.
Engineering applied
Dependency-graph analysis for affected-only builds, remote artifact caching, and pipeline parallelization — same Actions quota, radically different throughput. Right-sized K8s workloads via Terraform audits to cut cloud spend.
Output
1→20+ builds/day lower cloud cost 5+ yrs, multiple clients
